# TLA共創OS 公開β版 v0.2

## 公開先

既存の牧山式インテリジェンスのVercelプロジェクトに追加する独立ページです。

- ページ: `/co-creation`
- 公開データ/追加調査API: `/api/co-creation`
- 静的資産: `/co-creation-assets/`

既存の画面、既存DBの内容、既存cronは変更しません。新ページは独自HTMLとCSSを使用します。非公開の人脈・連絡先・調査履歴は読み込みません。ソースが公開されている組織はTLA会員やDAO参加者ではありません。

## 収録範囲

- GSIの名称コード台帳を固定URLから取得・リテラル解析し、行政区等の重複を除外します。元のv0.1は1,741件、47都道府県。台帳の取得は本番サーバーの外部接続に依存します。
- 取得不能時は、直前キャッシュがあればそれを表示し、なければ3自治体のみ表示して警告します。取得できない全国データを収録済みと装いません。
- 詳細資料: 三浦市、佐倉市、うるま市の9件。数値統計・全国の議事録分析は未取得。
- 企業/NPO: フォーバル、ベネッセ、クボタ、ソフトバンク、フローレンス、TOPPANデジタル。
- 照合: 13分野タグ。終了募集を除外し、既存連携は既存と表示。自治体・政策の評価点や事業成立確率は生成しません。
- 共創の保存: 利用者が押したときだけlocalStorage。サーバー・他の利用者には公開しません。ブラウザデータ削除で消えるのでJSON書出しを利用してください。

## 初回リリースの安全な既定値

一般閲覧と収録企業の照合は追加のキー設定不要です。未収録企業の追加AI調査は `TLA_PUBLIC_RESEARCH_ENABLED=1` がない限り無効です。新規利用者が既存のAIキーで無制限に課金を発生させる状態にはしません。

## 追加AI調査の有効化（管理者）

1. 同じSupabaseプロジェクトで `supabase/migrations/20260926_tla_cocreation_quota.sql` を実行する。既存テーブルや既存RLSは変更しません。
2. Vercelのサーバー環境変数に、既存の `OPENAI_SI_API_KEY`（または `OPENAI_API_KEY`）、`NEXT_PUBLIC_SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY` があることを確認する。値をチャットやブラウザ入力欄に貼らないでください。
3. 本番への反映前にPreviewでテストし、`TLA_PUBLIC_RESEARCH_ENABLED=1` を設定する。モデルを変える場合は `TLA_CO_CREATION_MODEL` を使用する（既定 `gpt-4.1-mini`）。既存 `OPENAI_MODEL` は変更しません。
4. 1社のテストで、同名法人、検索参照、原資料、費用・遅延を確認する。公開前にプロバイダー側の利用上限・アラートを設定する。

制限: UTC日付で全体30回、送信元3回。Supabaseのアドバイザリロックで複数インスタンスからの同時呼出しも一つの上限を共有します。失敗時も枠を消費します。1回最大2検索ツール呼出し・2,000出力トークン。これは金額ベースの厳密な月額上限ではありません。Vercel/DBの通信・ホスティング費用は別途です。

DB接続やRPCを検証できない場合は追加AI呼出しを拒否します。Origin確認はCSRF対策であり、本人認証ではありません。認証、Bot対策、長期利用者別課金は別段階です。公開研究を有効にしない限り外部AI課金はこの新機能から発生しません。

結果はOpenAIの実際の参照URL一覧と照合しますが、意味内容や法人同一性の完全な証明ではありません。AIの資料に含まれる指示には従わず、入力をデータとして扱います。結果のDB蓄積・共有はしません。元サイトを直接クロールする公開プロキシ機能はありません。

## プライバシー

追加調査で送るのは企業名、任意の公式URL、調査指示です。個人の連絡先やTLA非公開人脈は送らない設計です。OpenAIには `store:false` を指定しますが、API提供者の全ログの不存在を意味しません。

制限用テーブルは日替わりHMAC識別子・日付・回数のみ。IPの平文や企業名は保存しません。7日超の制限データは次回呼出し時に削除します。ホスティング事業者の通常アクセスログは別です。

## テスト

```bash
node --test tests/co-creation.test.mjs
```

作成環境で20項目の純粋ロジックテストに合格しています。Next.js本体のビルド、実Vercel URL、実Supabase、実OpenAIの成功は、このファイル作成時点では未確認です。公開完了は本番デプロイ結果とURLを別途確認してください。

## 無効化・ロールバック

追加調査のみ停止するには `TLA_PUBLIC_RESEARCH_ENABLED` を削除または `0` にして再デプロイします。今回追加したroute、lib/co-creation、public/co-creation-assetsを削除すると新ページを取り下げられます。既存DBは無変更なので既存画面のデータを巻き戻す必要はありません。依存ライブラリの既知脆弱性、WAF、監視・連絡窓口の整備は運用時に確認してください。
