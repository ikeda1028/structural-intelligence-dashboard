# 自治体統計を事業検討へつなぐ表示

更新：2026-09-27。対象画面：`/co-creation?municipality=01100` など、自治体台帳の詳細。

従来の「先頭18項目の数字カード」を廃止し、人口構成・出生死亡差・転入転出差、分母付き指標、比較対象、読み取り、提案前の調査項目を表示する。全89項目は分野別の原数値表に残す。これによって新たな自治体の予算本文・課題を調査済みにするものではない。

## 根拠

- [統計でみる市区町村のすがた2026](https://www.stat.go.jp/data/s-sugata/index.html)
- [基礎データの定義](https://www.stat.go.jp/data/s-sugata/pdf/kisodata.pdf)：PDF5ページ人口・世帯、6ページ産業、7ページ財政・教育を確認。年齢・世帯・業務集計の単位を区別。
- [利用上の注意](https://www.stat.go.jp/data/s-sugata/riyou3.html)：公表年と原表年、区域基準日、欠測・秘匿、不詳等による内訳不一致。
- [2024年人口移動報告](https://www.stat.go.jp/data/idou/2024np/jissu/youyaku/index.htm)：国内転入超過と国外移動等を含む社会増減は別。
- 原数値は既収録の `public/co-creation-assets/municipality-stats.json` を使用。原表リンクは既取得マニフェストの e-Stat A〜J 表IDに対応させた。今回、元の統計値は書き換えていない。

## 計算上の不変条件

- 年齢割合は3区分の合計（年齢既知人口）を分母とする。構成図は総人口を分母とし、差分の年齢不詳相当を明示する。両者を混同しない。
- 単独世帯・高齢単独世帯の割合は一般世帯が分母。高齢単独世帯は単独世帯の内数。
- 地方税／歳入は決算構成。自主財源比率・現在の予算余力とは呼ばない。
- 小学校児童／本務教員は児童教員比。学級人数・市立限定の値・教員不足率とは呼ばない。
- 民営従業者／事業所は平均規模。企業数・中小企業比率・DX普及率ではない。
- 同年・想定単位・正の分母を満たさない場合は算出不可。欠測・秘匿を0にしない。
- 出生死亡差と転入転出差は別表示。異なる年・統計の人口を差し引いて増減率や住民当たり経費を作らない。

## 比較

国勢調査人口で1万未満／1〜5万未満／5〜10万未満／10〜30万未満／30〜100万未満／100万以上に区分し、市・町村・特別区を分ける。自自治体を除き、同じ原表年・式で算出可能な自治体が3以上ある場合のみ中央値を示す。対象名と値を画面から確認できる。国の類似団体区分ではなく、行政権限や地理的条件の差は未調整。
