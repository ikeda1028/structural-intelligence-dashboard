## 2026-09-26：既掲載5市の訂正

対象は既掲載の横浜・大阪・名古屋・札幌・福岡の5市。8 PDFと1 HTMLの指定箇所を確認した部分レビューであり、100市調査完了ではない。

公開データの `documents` に資料単位の要約、確認範囲、PDFページ、事実の状態、原単位の予算、限界を収録した。`source_leads` は所在・案内のみで本文レビュー件数から除外する。総合DX段階は根拠不足のため null に戻した。

## 主な訂正

- 大阪市：旧出典のPDFはDX予算とは別内容。正しい財政局PDFに変更し、配分をサービスDX36億2,000万円、行政DX63億5,700万円、都市・まちDX4億2,500万円に訂正。合計104億200万円。AIエージェント2業務は年度目標。
- 横浜市：契約結果一覧を現在の参入入口として扱わない。共創事業の2026年度細目は黒塗りであり、読める2025年度細目を流用しない。道路AI戦略は2024年の状態で、現在の導入状況を断定しない。
- 名古屋市：要求額、財政局案、予算案、局経常経費内対応を区別。要求概要の生成AI項目だけから採用・予算額を断定しない。
- 札幌市：予算案資料の事業別要約へ差し替え。国への要望案を市の実装実績としない。道路AI点検を含む事業総額をAIだけの費用としない。
- 福岡市：計画と従来の実績の列を区別。総務企画局AI事業55,809千円と、複数局のAI施策6,372万円を二重計上しない。

## 再確認手順

1. JSONの公式URLから原資料を取得し、対象年度・資料名を照合する。
2. `review_scope` と `pdf_pages` の箇所を読み、`findings.locator` ごとに本文と表を照合する。ページの抽出テキストだけで列の対応が曖昧な場合は画像で確認する。
3. 予算・成果・導入状況は資料の記載時点に限定する。更新資料を読まない限り「現在の稼働」「最新予算」「募集中」とは扱わない。
4. 質疑・答弁、条例、個別契約、利用実績等の不足は `next_tasks` に残す。
5. `node --test tests/municipal-research.test.mjs` と既存の `npm run test:co-creation`、`npm run build` を実施する。テストはデータ構造・表示・集計の退行検知であり、原資料の人手照合の代替ではない。

既存の内部調査データ・人脈・連絡先は使用していない。公開するのは公式資料の要約と出典のみ。
