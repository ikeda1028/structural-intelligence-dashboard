# 100自治体のDX確認段階

## 対象と判定単位

2026-09-27時点の `major100-research.json` の本文レビュー済み資料を再整理する。新規の網羅的実態調査や自治体の公式格付けではない。自治体ごとに、**収録資料内の特定業務で裏付けられた最も先の段階**を表示し、その対象業務を必ず併記する。自治体全体の成熟度を意味しない。既存の `dx_stage.overall: null` は維持する。

全庁展開の広さと、個別業務の効果測定は別軸。全庁ライセンス配布だけで効果測定・データ連携を認定しない。調達機会や企業の参入余地も段階から推測しない。

## 分類（順位・優劣ではなく、資料で確認できた到達点）

| コード | 表示 | 必要な根拠 |
| --- | --- | --- |
| U | 判定保留 | 本文の確認範囲では、下記の状態を裏付けられない。未導入ではない。 |
| P | 計画・予算・調達 | DXの計画・予算計上・募集・選定等。実証開始・本番稼働の事実は未確認。未来の開始日もここに留める。 |
| T | 実証・試行 | 実際に開始・実施した試行を確認。本番稼働は未確認。試行の成果があっても本番の成果測定段階には上げない。 |
| O | 本番運用 | 住民向けサービスの提供開始、職員の継続業務利用、実際の利用件数等。本番での効果測定は未確認。利用件数や導入数だけでは効果としない。 |
| M | 本番運用＋効果測定 | 本番業務に対する削減時間・処理時間・利用者満足度等の結果がある。推計・自己申告も区別して明記し、費用削減や因果効果に読み替えない。目標値や評価項目の指定だけでは不可。 |
| I | 効果に基づく継続改善 | 本番の効果を測定し、その結果に基づく具体的改善を実施、その後の再測定まで裏付けられる。PDCAの方針や単年度の改善件数だけでは不可。 |

## 記録

各自治体を手作業で本文レビュー・findings・limitsと照合し、`stage`、`scope`（裏付けられた業務・範囲）、`reason`、`evidence`、`limitations` を付ける。`evidence` は既存資料IDと0始まりのfinding_indexで参照し、判定に直接使う根拠を `role: stage`、補足を `role: context` とする。公開画面には資料名・該当箇所・根拠文を表示する。

同じ自治体でAIが計画段階、オンライン申請が運用段階など混在し得る。表示される1分類で全サービスをまとめて断定しない。技術導入仮説、将来目標、資料の所在確認のみを実績根拠にしない。過去の実績はその年度の確認に限定し、現在も同じ状態と断定しない。

## 検証

- 対象100自治体と分類の集合が一致し、コードが重複しない。
- 全判定の資料ID・finding_indexが既存本文レビュー内に存在する。
- P以外の判定に、予算だけでなく運用・実施・効果の直接根拠があるか目視点検する。
- 既存の資料・未確認事項・総合評価保留を保持する。
- 分類別件数はデータから算出し、分類絞り込みと各自治体の根拠表示をテストする。

## 2026-09-27の分類結果

100自治体を人手で判定し、資料IDと該当findingを照合した。計画・予算・調達37、実証・試行6、本番運用45、本番運用＋効果測定12、効果に基づく継続改善0、判定保留0。Iが0件であるのは、今回の収録資料で改善実施と再測定の連鎖まで裏付けられないためであり、該当する自治体が存在しないという意味ではない。

那覇市・高松市は実証時の効果を本番効果へ転用せずO。京都市・西宮市・横須賀市は実証結果に留まるためT。奈良市・郡山市等のMには推計・システム算定、鹿児島市のMには職員の主観的満足度が含まれ、いずれも実測の金銭効果とは扱わない。春日井市・大分市の将来開始、尼崎市の開始前発表はP。大津市・福山市・千葉市等は地域企業・人材支援施策を対象としており、庁内の稼働状況ではないことを明示した。

全庁ライセンス提供があっても全職員の実利用やデータ連携は保証しない。既存0〜5の分野別成熟度スケールとは別の `dx_evidence` として格納し、総合評価保留は維持。既存100自治体のデータは、この追加フィールド以外が変更されていないことを照合した。

データは `major100-research.json` の `dx_classification`（基準）と各自治体の `dx_evidence`（個別判定）に収録。既存資料の本文確認範囲を超える追加調査を行ったという表示にはしない。分類の再統合は `scripts/integrate-dx-classification.mjs` に100件の手動レビューJSONを渡して行う（参照ID・対象集合の検証付き）。
