# 100自治体・企業関与の出典付き整理

対象は主要100自治体レポートの収録業務・公開資料。全調達の網羅調査ではない。資料本文から法人名・業務・関係の段階・時点を確認し、未特定を「受託企業なし」にしない。将来価値カードの仮説に出てくる企業・役割は受託実績に用いない。

## 関係の分類

- contracted: 委託先・契約先・受託者又は実施した構築事業者を本文で確認。契約期間未確認なら現在も契約中とは表示しない。
- designated_operator: 自治体施設の指定管理者として実施を確認。一般の業務委託とは別に表示する。
- selected: 受託候補者・優先交渉権者の選定。契約締結・履行は未確認。
- operating_provider: 実施中又は実施したサービスの提供企業を明示。直接契約・元請の特定とは別。
- pilot_partner: 実証の提供者・参加者。通常の業務受託・本番稼働とは別。
- agreement_partner: 協定・共同研究等。受託契約とは別。
- planned_provider: 導入予定のサービス提供者を明示。開始予定日経過を稼働確認に置換しない。
- product_provider: 自治体の製品利用と製品提供会社の対応を別々の一次資料で確認。販売・導入・保守の直接受託者は未特定。

企業の強みは収録した業務の分析であり、企業全体の競争優位・品質保証ではない。契約・実施経験、選定された提案分野、協定等の関与領域を区別し、各分析に関連案件を付ける。導入件数や関係自治体数を全国シェアと表示しない。親会社・子会社・同名会社を無根拠に統合しない。支店名・資料上の表記を残す。

## 調査バッチの形式

JSON: {municipalities: {"5桁コード": {reviewed_document_ids: [既存doc.id], review_note: string, relations: [...]}}}

relation: {company_name, company_kind: "company"|"nonprofit"|"public_body", company_url: string|null, identity_source: {url,title,note}|null, source_name: string, status: 上のenum, business: string, period: string, capability: string, strength_note: string, limitation: string, evidence: [{document_id:string|null,url,title,locator,observation,checked_at:"2026-09-27"}]}

- capabilityは短い業務分類（窓口・申請、生成AI・文書検索、電話・相談、基幹・データ連携、電子契約・会計、地理空間・インフラ、交通、研修・人材、住民参加、その他）。
- observationは本文の要約。コピー長文にしない。PDFはページ番号、HTMLは見出しを付ける。
- 同社同自治体でも異なる業務・関係は別行。企業同定の公式URLが不明ならnull。推測URLを掲載しない。
- 既存doc本文の追加確認又は追加一次資料を確認。現行関係を無根拠に断定しない。何も確認できない自治体も空relationsとreview_noteを必ず記録。
- 資料・製品の一般的な脚注（Adobe等）、広告、ナビゲーション、検索スニペットだけの企業名は除外。契約限度額は契約額にしない。個人連絡先は収録しない。

## 初回公開データ（2026-09-27）

- 正本は `public/co-creation-assets/municipal-companies.json`。100自治体の既存214資料を抽出対象とし、32自治体・39企業＋1団体・45関与を掲載。残る68自治体は関与未特定であり、受託者がいないとはしない。
- 委託先・構築実績確認は4自治体・11企業・12関与。候補者、協定等をこの数へ合算しない。現在の契約継続を確認した件数ではない。
- `screened_document_ids` は既存要約・抽出本文の点検対象。今回の全文精読件数ではない。採用案件の追加確認箇所は各 `evidence.locator` に限定する。

- 北区3協定、大阪市の引越し連携、さいたま市の相談AI協定は関連公式ページを追加確認。`document_id:null` はこれらの追加資料で、出典欠落ではない。
- 企業リンクは本サイト内の企業別プロフィールを全件に用意。企業公式URLは法人同定に使った公式ページが確認できたものだけ掲載。法人名は資料当時を保持し、旧商号の無根拠な統合はしない。

## 維持・検証

`municipal-companies.js` を両自治体レポートと企業索引で共有。自治体⇔企業の双方向リンク、関係区分フィルタ、案件から読み取れる強み、出典・期間・限界を表示する。企業JSONの取得失敗は「未特定」と区別し、元の資料レポートは継続表示する。

更新時は `node --test tests/*.test.mjs` を実行。企業・関与・自治体件数の期待値も実データと照合して更新する。親会社と子会社を統合しないこと、同社同市の複数案件を自治体数へ重複加算しないことを確認する。未特定自治体の次工程は業務名に対応する契約・落札結果と指定管理者選定結果の個別照合。
